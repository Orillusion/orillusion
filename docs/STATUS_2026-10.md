## 四、已知限制与注意事项

- **运动模糊**只对相机运动生效。
- **点光 / 聚光的 `radius` 默认 0.001**，而衰减里有 `1 / radius`，默认值会让灯光亮 1000 倍。
  示例里都手动设了 `radius`（0.01 或 1）。这是 API 约定问题，未改动，建议后续统一单位。
- **`ComponentCollect.waitStartComponent` 是全局的**，跨引擎实例共享。一个从未启动的场景里的组件
  会在别的引擎的帧里被启动。本轮修了后处理这一条触发路径，根因（待启动列表应按引擎隔离）还在。
- **同一页面连续创建约 45 个引擎实例后渲染进程会卡死**，说明 `dispose()` 后仍有 GPU / WASM 资源滞留。
  只在批量跑示例时遇到，正常应用不会触发，但值得排查。
- **截图基准**在 Mac Metal 上生成，并用 SwiftShader 启动参数跑过一遍通过；未能确认该参数在 macOS 上
  确实切换到了软件适配器，首次在 Linux CI 上运行时需要留意，必要时在 CI 环境重新生成基准。
- `@dimforge/rapier3d-compat` 初始化警告、`packages/geometry/tsconfig.json` 缺装饰器开关、`APatch`
  自引用装饰器三个小问题仍未处理。
